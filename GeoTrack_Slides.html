Slide 2: Real-World Wireless Positioning Challenges

1. Cold Start TTFF

Downloading 50 bps broadcast satellite ephemeris takes 30–60 seconds under standalone GPS.

2. Multipath Fading

Reflections off high-rise buildings in urban canyons cause abrupt 50m–150m false jumps.

3. Receiver Clock Bias

Quartz clock thermal drift causes phantom movement and fake speed readings when stationary.

4. Network Variance

Disparity between GNSS (±3m), Wi-Fi (±20m), and Cellular Cell-ID (±1000m).

Project Goal:

Design an intelligent software-defined filtering pipeline to suppress multipath spikes, reduce latency via A-GPS, and deliver smooth sub-10m visualization.

🎙️ Speaker Script: "Mobile GPS isn't perfect out of the box. In cities like Mumbai, multipath reflections cause sudden 100m jumps, and cold starts take 45 seconds. GeoTrack directly addresses and eliminates these physical wireless impairments."

Slide 4: Mathematical Foundations: Geodesy & Trilateration

1. 4-Satellite Pseudo-Ranging

Requires ≥ 4 satellites to solve 4 unknowns (x, y, z, Δtb):

ρi = √((Xi-x)2 + (Yi-y)2 + (Zi-z)2) + c(Δtb - Δti) + Ii + Ti

Δtb = Quartz clock bias; Ii, Ti = Atmospheric delays.

2. Geodesic Haversine Formula

Computes true surface distance on WGS-84 oblate spheroid (R = 6,371,000m):

a = sin2(Δφ/2) + cos(φ1)cos(φ2)sin2(Δλ/2)
d = 2R · atan2(√a, √(1-a))

Eliminates planar flat-surface distortion.

🎙️ Speaker Script: "Why are 4 satellites needed? The 4th satellite is strictly required to solve for receiver clock bias offset Δtb. We calculate distance using the Haversine formula on the WGS-84 ellipsoid to prevent spherical distortion errors."

Slide 5: Signal Processing: 1D Kalman Filter & Outlier Gate

Data Flow: Raw GPS Fix → Kinematic Jump Gate → Stationary Deadband → 1D Kalman Filter → Clean Route

Outlier Jump Gate

Dmax = (vmax · Δt) + 2.5 · σaccuracy

Rejects multipath reflection artifacts where velocity exceeds realistic vehicular limits (v > 45 m/s or 162 km/h).

1D Discrete Kalman Filter

Measurement Variance R = (σaccuracy / 111320)2
Kalman Gain K = P / (P + R)

Dynamic variance: when GPS uncertainty increases, Kalman gain drops to trust kinematic momentum over noisy readings.

🎙️ Speaker Script: "Our filtering pipeline in `src/utils/geoDistance.ts` checks every frame against a 45 m/s velocity gate. If a multipath jump occurs, it is dropped. Accepted points pass into our 1D Kalman filter, where variance R scales dynamically with reported GPS accuracy."
